# Rin

Trợ lý AI chạy hoàn toàn trên trình duyệt. Chỉ có một file `index.html`, không cần server.

## Dùng thế nào

1. Lấy key Gemini miễn phí ở https://aistudio.google.com (Get API key).
2. Mở trang, nhắn một tin. Trang sẽ hỏi key, key chỉ lưu trong trình duyệt của bạn.
3. Nút **Cài đặt** để đổi key hoặc tên model khi cần.

## Đưa lên web bằng GitHub Pages

Settings > Pages > Branch: `main` > Save. Vài phút sau có link `https://<tên-github>.github.io/<tên-repo>`.

Không ghi key vào file. Mỗi người mở trang tự nhập key của họ.
